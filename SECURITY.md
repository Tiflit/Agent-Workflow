# Security Policy & Privacy Guidance

> **Status:** Candidate security policy template (v0.1 draft).

## Reporting Vulnerabilities & Sensitive Concerns

- **No Public Disclosure**: Do **NOT** report security vulnerabilities, credentials, or privacy leaks in public GitHub Issues, discussions, or pull requests.
- **Reporting Contact**: Send sensitive security disclosures directly to the project maintainer via: `<security-contact@example.com>` *(unconfigured placeholder)*.
- **Unconfigured Channel Warning**: Until the human repository owner replaces this placeholder and configures an authenticated private reporting channel, **no private reporting channel exists**. Contact the repository owner out-of-band for sensitive concerns.

## Pending Governance Decisions

## Privacy Invariants

Agents operating under this workflow must never commit personal access tokens, local machine usernames, private absolute filesystem paths, or confidential customer telemetry to tracked git repositories.
