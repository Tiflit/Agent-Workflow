# Security Policy & Privacy Guidance

> **Status:** Candidate security policy template (v0.1 draft).

## Reporting Vulnerabilities & Sensitive Concerns

- **No Public Disclosure**: Do **NOT** post security vulnerabilities, sensitive credentials, or personal privacy leaks in public GitHub Issues, discussions, or pull requests.
- **No Active Private Channel**: In this starter template, **no configured private reporting channel exists**. Do NOT send sensitive security disclosures to unconfigured placeholder addresses.
- **Reporting Procedure**: Contact the repository owner directly out-of-band via an established private communication channel to report sensitive security matters.

## Pending Governance Decisions

In accordance with [`KERNEL.md`](KERNEL.md) K7:
- **License Selection**: The software license for this repository remains a pending human owner decision. AI agents MUST NOT unilaterally select, add, or infer a license.
- **Security Infrastructure**: Private vulnerability reporting mechanisms, security responder contacts, and encryption keys remain owner-administered decisions.

## Privacy Invariants

Agents operating under this workflow must never commit personal access tokens, local machine usernames, private filesystem paths, or confidential customer telemetry to tracked git repositories.
